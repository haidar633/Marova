# Marova

A personal sexual activity and health tracking application built with Laravel and Livewire.

## Features

**Activity Tracking:**
- **Attempts**: Track sexual attempts with success status, satisfaction ratings (0.5-5 stars), duration, positions, lubrication usage, and detailed notes
- **Sex Tracking**: Record sexual encounters with partner ratings and descriptions
- **Masturbation Tracker**: Monitor solo activity patterns

**Content Management:**
- **Partners**: Manage partner profiles with images, star ratings, last meeting dates, and descriptions
- **Positions**: Catalog sexual positions with photos and favorite positions
- **Favorite Hubs**: Organize preferred content and resources

**Tools & Reports:**
- **Spin the Wheel**: Random selection tool for activities
- **Reports**: Generate analytics and insights from tracked data
- **Activity Tracker**: Monitor overall activity patterns

**Administration:**
- Role-based access control (Admins, Staff, Users)
- User profile management
- Audit logging for data changes

Built with Laravel 11, Livewire 3, Bootstrap, and includes features like PDF generation, activity auditing, and permission management.
